# Icon generation

Built-in ImageGen was used with a transparent background. Final prompt:

> Use case: stylized-concept. Asset type: sprite sheet for a Minecraft Forge 1.20.1 survival HUD. Create a clean 3 by 2 grid of SIX separate square mood status icons, each centered in its own equal-size cell with generous transparent padding. Reading left to right, top row: Tense (single alert eye with tense brow), Fearful (shivering face with wide eyes), Panicked (shocked face and radiating stress marks). Bottom row: Irritated (angry brow and small stress spark), Exhausted (drooping sleepy face), Relieved (calm face with relaxed breath). Cohesive original 32-bit pixel art, dark desaturated olive and charcoal palette with restrained amber and rusty red status accents, crisp silhouette readable at 20x20 pixels, no text, no letters, no numbers, no frames, no shadows outside the icons. Perfectly aligned 3x2 grid, six distinct motifs, transparent background.

The bottom-left icon was later replaced with Pain using built-in ImageGen. Its new 512 x 512 cell was placed into the original 1536 x 1024 sprite sheet; the other five cells are pixel-identical to the previous version. Edit prompt:

> Use case: precise-object-edit. Asset type: Minecraft Forge HUD sprite sheet, 3 columns by 2 rows, exactly 1536 x 1024 pixels with six 512 x 512 cells. Edit ONLY the bottom-left cell (row 2, column 1), currently an angry hooded survivor with red spark. Replace that character's expression with clear physical pain: same olive hood, same masked survivor, one eye squeezed shut, grimacing and clutching the side of the head or shoulder, a small subtle red wound mark or red pain lines near the head. Keep the same pixel-art style, chunky dark pixel outlines, lighting, proportions, palette and black background. The other five cells must remain visually identical to the source, same positions and details. No text, no borders, no extra characters. Output the full original sheet with only that one cell changed.
