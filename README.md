# Lazarus Moodles

A Forge 1.20.1 HUD mod for Project Lazarus. Each player has six independent moodles with four visible stages: Tense, Fearful, Panicked, Irritated, Exhausted, and Relieved.

Moodles respond to nearby hostile mobs, light, health, damage, sprinting, hunger, and the transition back to safety. They are informative and do not add combat penalties. Values persist with the player and synchronize from the server to that player's HUD.

Install the built JAR in `mods` on both the server and every client. The icons are original generated pixel art stored in `assets/lazarusmoodles/textures/gui/moodles.png`. All mod text is English.

Download the ready-to-install JAR from [`dist/lazarusmoodles-1.0.0.jar`](dist/lazarusmoodles-1.0.0.jar), or build it with JDK 17: `gradlew build`.
